# 🎬 67movies — Dark Premium Cinema Platform

**67movies** — самостоятельный стриминговый онлайн-кинотеатр с оригинальным дизайном в эстетике **Dark Premium Cinema**, независимой модульной архитектурой, встроенным адаптером плагинов Lampa и кастомным адаптивным видеоплеером (HLS.js / Shaka Player) с поддержкой Smart TV (10-foot UI).

## 🚀 Возможности главной страницы

1. **Оригинальный геометрический логотип `67movies`:**
   * Числа **67** — центральный геометрический акцент с неоновым свечением.
   * Слово **movies** — сдержанный геометрический гротеск с широким трекингом.
   * Компактная версия для мобильных устройств и favicon.
2. **Динамическая верхняя панель (Navbar):**
   * Полупрозрачная шапка с размытием (`backdrop-blur-md`).
   * Плавный переход в более компактный и непрозрачный режим при прокрутке страницы.
   * Навигация: **Главная**, **Фильмы**, **Сериалы**, **Жанры**, **Избранное**.
   * Быстрый поиск и переключатель профилей пользователя.
3. **Главный баннер (Hero Section):**
   * Широкоформатный backdrop с мягким виньетированием слева и снизу для идеальной читаемости.
   * Название, год, жанры, возрастной рейтинг (16+/18+), оценка TMDB (★ 8.6), синопсис.
   * Кнопки **«Смотреть»** (акцентная `#8065FF`) и **«Подробнее»** (стеклянная).
   * Интерактивный слайдер/свитчер для мгновенного переключения между 5 промо-фильмами.
4. **Все 7 ключевых контентных блоков:**
   * **Продолжить просмотр** (карточки 16:9 с полосой прогресса, оставшимся временем и серией).
   * **Популярное сегодня** (тренды последних 24 часов).
   * **Новинки кино** (мировые премьеры в 4K).
   * **Популярные сериалы** (рейтинговые драматические и фантастические шоу).
   * **Выбор редакции** (шедевры с рейтингом 8.5+).
   * **Рекомендуем для вас** (персонализированная лента на основе вкусов).
   * **Последние добавленные** (свежие пополнения стриминга).
